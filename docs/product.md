# Продукт

## Кто пользуется сайтом

1. **Покупатель** — заходит на `podium-sale.ru` (обычно с рекламы/
   рассылки/соцсетей), смотрит каталог последних экземпляров
   светильников, звонит или оставляет заявку.
2. **Сотрудник салона «Подиум»** — не разработчик, ведёт каталог
   через `admin.html`: добавляет/убирает позиции по мере продажи,
   меняет цены, курс валюты, загружает фото.
3. **Владелица бизнеса** — финальный согласующий всех изменений,
   задаёт бизнес-правила (например, про курс валюты и про недопустимость
   фиктивных "старых цен").

## Ключевые продуктовые решения и их обоснование

### Цены: EUR в базе, RUB на витрине

Исторически позиции вели в евро (закупка у европейских фабрик).
Чтобы не пересчитывать вручную 288 позиций при каждом колебании
курса, было решено: **база данных всегда в евро**, а перевод в рубли
для покупателя происходит на лету по курсу, который задаётся одной
кнопкой в админке («Применить курс») и мгновенно влияет на всю
витрину без редеплоя.

> Это решение прошло через несколько итераций обсуждения с
> владелицей в процессе разработки — финальная и единственно верная
> версия: сотрудник в админке работает только с евро, покупатель на
> сайте видит только рубли. Предыдущие промежуточные формулировки
> задачи (показывать и евро, и рубли, или хранить рубли как базу) —
> были отклонены и не должны возвращаться без явного нового решения
> владелицы.

### Никогда не придумывать "было/стало" цены

Поле `old_price` (зачёркнутая "старая" цена со скидкой) заполняется
**только** когда есть реальный подтверждённый источник этой цены.
Если источника нет — поле остаётся пустым, скидка на карточке просто
не отображается. Это не техническое, а юридическое ограничение
(ФЗ «О рекламе», ст. 5 — запрет недостоверной рекламы цен), и его
нельзя "упрощать" даже ради визуальной привлекательности карточек.

### Отказоустойчивость на нестабильных сетях — часть продукта, не техдолг

Значительная часть аудитории — пользователи в России, у части
операторов периодически случаются проблемы с доступом к иностранным
сервисам (Supabase хостится в Швеции). Решение показывать
резервную копию каталога (`lamps.json` с того же российского домена)
при сбое прямого запроса — это сознательное продуктовое требование
"сайт не должен показывать пользователю ошибку из-за временной
проблемы с сетью", а не просто техническая подстраховка.

### Прямой переход на страницу каталога

По явному запросу владелицы была добавлена возможность ввести номер
страницы и сразу перейти на неё, в дополнение к обычным "вперёд/
назад" — при большом каталоге (288+ позиций, 16 на страницу — это
18+ страниц) пролистывание по одной странице было неудобным.

## Коммуникация с сотрудниками

Для новых сотрудников, которых подключают к работе с админкой,
владелица использует собственные инструкции по использованию панели
курса валюты (составлены по итогам разработки этой функции) — при
изменениях в UI/логике админки стоит сверяться, не разошлась ли
текущая инструкция для сотрудников с реальным поведением интерфейса.

## Что сознательно НЕ входит в продукт (на данный момент)

- Онлайн-оплата/корзина — сайт не предназначен для прямой продажи
  онлайн, только для сбора заявок/звонков.
- Личный кабинет покупателя.
- Многоязычность — сайт только на русском.
- Push/email-уведомления покупателям об изменении цены/наличия.
